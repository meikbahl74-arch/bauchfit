BAUCHFIT 3.2 – PRÜFVERSION

Diese Version baut auf BauchFit 3.1 auf. Der Programmcode enthält 78 eindeutige Standardübungen. Nutzer können eigene Übungen mit Beschreibung, Kategorie, Level und optionalem Foto hinzufügen, bearbeiten und löschen. Eigene Übungen werden lokal im Browser gespeichert und sind nicht automatisch geräteübergreifend synchronisiert.

BILDER
Die ZIP enthält 66 Bilddateien im Ordner exercises. Die Bildpfade für die Trainingsansicht verweisen nun ebenfalls auf diesen Ordner. Für Zuordnungen ohne eindeutig passendes Motiv wird ein neutraler Platzhalter angezeigt, statt ein sachfremdes Bild einzublenden. Einige Varianten teilen sich ein Bild, wenn sie dieselbe Grundbewegung darstellen.

WICHTIG
Die Zahl 99 aus älteren README-Texten war nicht korrekt für die tatsächlich im JavaScript vorhandene Standardliste. Die aktuelle Liste umfasst 78 eindeutige Einträge.

INSTALLATION
Den vollständigen Inhalt dieses ZIPs in das GitHub-Repository hochladen und vorhandene Dateien ersetzen. Den Ordner exercises vollständig mit hochladen. Anschließend GitHub Pages neu deployen und die App im Browser aktualisieren.
