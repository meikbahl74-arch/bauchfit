BauchFit PWA – erster funktionsfähiger Prototyp

Enthält 30-Tage-Challenge, drei Niveaus, zeitbasierte Übungen (alle Stationen in Sekunden), Aufwärmen/Dehnen, Countdown, Pause, Überspringen, lokalen Fortschritt sowie Sicherungsexport/-import.

Installation auf iPhone: Dateien auf einen HTTPS-Webhost laden (z. B. GitHub Pages), Website in Safari öffnen > Teilen > Zum Home-Bildschirm. Eine ZIP-Datei allein installiert keine PWA.

Hinweis: Übungsbilder sind vorerst Emoji-/Symbol-Platzhalter, keine echten Übungsfotos. Vor Veröffentlichung sollten passende Bilder eingebaut und auf verschiedenen iPhones getestet werden.
